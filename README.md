# Подорожі — багатосторінковий вебсайт

Навчальний проєкт з інформатики: багатосторінковий сайт туристичної тематики,
створений на чистому HTML і CSS.

## Сторінки

| Файл | Призначення |
|------|-------------|
| `index.html` | Головна: банер, переваги компанії, заклик до дії |
| `about.html` | Про нас: інформація про команду та підхід |
| `destinations.html` | Популярні напрямки: Париж, Нью-Йорк, Токіо |
| `gallery.html` | Галерея фотографій з подорожей |
| `contact.html` | Контактна інформація та форма зворотного зв'язку |

## Структура проєкту

```
Travels/
├── index.html
├── about.html
├── destinations.html
├── gallery.html
├── contact.html
├── style.css
├── README.md
└── img/            # логотип і фотографії
```

## Технології

- HTML5 (семантична розмітка)
- CSS3 (Flexbox, Grid, адаптивна верстка, анімації)
- Google Fonts: Lora для заголовків, Arial для основного тексту
- Фотографії: Unsplash (безкоштовна ліцензія)

## Як запустити

Відкрити `index.html` у браузері (Chrome, Opera або Edge).
Інтернет потрібен лише для завантаження шрифту Lora — решта працює локально.
